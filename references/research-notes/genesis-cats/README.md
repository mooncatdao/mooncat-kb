# Genesis Cats research notes

This directory is a compact, audit-oriented record for the Genesis population
reconstruction. It preserves only concise paraphrases of the facts used by the
curated dataset; it is not an article archive or a substitute for the linked
sources.

`SOURCES.json` records source class, trust, access result, and a SHA-256 of
each bounded note. Sources that could not be directly retrieved are retained
with an explicit inaccessible status and do not support imported claims.
